# 3分钟演示脚本

演示前确认Python 3.12、本地Ollama及既有数据库副本可用，按 [README](../README.md) 启动网页。只使用演示政策，不展示终端绝对路径或原始报告路径。现场问答会实际调用已配置资源，模型输出可能波动。

| 时间 | 操作 | 讲解要点 |
| --- | --- | --- |
| 0:00–0:25 | 展示标题与问题输入区 | “这是企业内部政策查询演示，覆盖住宿、餐饮、交通和年假。员工可以直接提问并查看依据；当前知识源只有7条政策，范围明确。” |
| 0:25–1:05 | 输入“一线城市住宿报销标准是多少？”并提交 | “先检索政策，再重排序筛选。回答应展示500元/天的标准及hotel_001完整原文。标准不能自动理解为固定补贴或实际可报金额。”指出状态与引用编号、原文件。 |
| 1:05–1:50 | 输入“出差餐饮花了160元，是不是超过100元的部分也能报？”并提交 | “政策只规定每天100元补贴，没有明确超出部分的报销规则。系统展示已知标准并说明无法确认，不承诺超出60元一定能报或不能报。此类问题由确定性保护处理，可以跳过生成。” |
| 1:50–2:30 | 展开“检索详情”，依次指向三个阶段 | “retrieved是初次向量召回，距离通常越小越接近；reranked是BGE评分排序；final_policies是阈值与条件筛选后候选，可能含补检索结果。它们不是答案正确率，候选也不等于最终引用。上方引用卡片来自policies。” |
| 2:30–3:00 | 收起调试区，说明评测与限制 | “该次24题回归自动指标达到100%，状态指标只计12题；这不是语义准确率，题集也已经用于多轮修复。H09仍可能引用格式拒答。项目展示需求分析、RAG集成、保护规则和评测交付，尚非生产系统。” |

若普通住宿问题遇到引用格式失败，说明系统会丢弃错误模型正文，满足有限问法和可信证据要求时独立返回原文；若仍保守拒答，如实说明，不把结果改成成功。模型服务不可用时展示错误状态，不把历史结果冒充实时回答。
